# IE on AI

The published pages of <https://ie-on-ai.github.io>: guides for people solving production, simulation and equipment
problems, each with an AI file (an Agent Skill) a reader can give their own assistant. Pages are in English and Korean.

This repository holds only the built site. Nothing is edited here by hand.
